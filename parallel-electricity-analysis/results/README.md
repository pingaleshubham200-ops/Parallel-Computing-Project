# Experimental Results & Performance Benchmarks

This directory contains analytical outputs, performance profiling metrics, and visualization figures generated by the **Hybrid MPI + OpenMP** parallel pipeline and the sequential baseline on the **Kaggle Smart Grid Real-Time Load Monitoring Dataset**.

## Directory Structure
- `hybrid/`: Analytical outputs from the distributed Hybrid MPI + OpenMP implementation (`summary.csv`, `hourly_stats.csv`, `daily_stats.csv`, `anomalies.csv`).
- `sequential/`: Analytical outputs from the single-threaded sequential reference baseline.
- `plots/`: Publication-quality Matplotlib figures.
- `benchmark_results.csv`: Multi-configuration Hybrid MPI + OpenMP scaling benchmark table.

## Output Files Description

### 1. `hybrid/summary.csv`
Contains high-level metrics of the analyzed smart grid dataset:
- Total records read, clean valid records (50,000), and malformed records (0).
- Sampling interval ($\Delta t = 15.0$ minutes = $0.25$ hours).
- Mean active load (6.3208 kW), standard deviation (2.9901 kW), min (1.0892 kW), and maximum peak demand (12.1032 kW).
- Peak timestamp (`2024-08-13 23:00:00`).
- Cumulative grid energy consumed (79,010.14 kWh).
- Total solar generation (313,441.96 kWh) and wind generation (187,603.90 kWh).
- Total renewable energy generation (501,045.86 kWh).
- Total dynamic electricity tariff cost ($23,652.72 USD).
- Average grid line voltage (229.9979 V) and average power factor (0.9000).
- Grid reliability metrics: total overload intervals (4,956 intervals) and transformer faults (1,460 intervals).
- Diurnal peak hour by average load (14:00, 6.4875 kW) and peak hour by spike (23:00, 12.1032 kW).
- Calendar peak day by average load (2024-10-18, 7.3404 kW) and peak day by spike (2024-08-13, 12.1032 kW).
- Statistical anomaly threshold ($\mu + 1.8\sigma = 11.7029$ kW) and total flagged grid events (6,396).
- Profiling breakdown: file I/O time, MPI scatter time, OpenMP computation time, MPI reduction time, and end-to-end wall time.

### 2. `hybrid/hourly_stats.csv`
Diurnal profile aggregated across the 24 hours of the day (00:00 to 23:00):
- `Hour`, `Count`, `Mean_Power_kW`, `StdDev_kW`, `Min_Power_kW`, `Max_Power_kW`, `Total_Energy_kWh`, `Solar_kWh`, `Wind_kWh`, `Renewable_kWh`, `Overloads`, `Faults`.

### 3. `hybrid/daily_stats.csv`
Daily aggregated metrics indexed by calendar date (`YYYY-MM-DD`):
- `Date`, `Count`, `Mean_Power_kW`, `StdDev_kW`, `Min_Power_kW`, `Max_Power_kW`, `Total_Energy_kWh`, `Renewable_kWh`, `Cost_USD`, `Overloads`, `Faults`.

### 4. `hybrid/anomalies.csv`
List of all flagged records exceeding the statistical threshold, grid overload conditions, or transformer faults:
- `Timestamp`, `Epoch_Seconds`, `Active_Power_kW`, `Voltage_V`, `Z_Score`, `Is_Overload`, `Is_Fault`, `Alert_Category`.

### 5. `plots/`
- `fig1_hourly_power_profile.png`: Diurnal load profile showing mean load, $\pm 1\sigma$ band, max spikes, and renewable energy comparison.
- `fig2_daily_consumption.png`: Daily average power trends, max peak spikes, and daily renewable generation vs grid load.
- `fig3_anomalies_distribution.png`: Scatter plot of detected grid anomalies and overloads colored by Z-score intensity.
- `fig4_execution_time_breakdown.png`: Stacked runtime breakdown comparing data ingestion, MPI scatterv, OpenMP thread computation, and MPI collective reductions.
- `fig5_speedup_and_efficiency.png`: Strong scaling speedup curve and parallel computational efficiency across process/thread configurations.
